
# Audio Amp Board

This was one of the first PCBs I designed! It's an analog audio amplifier, with independent amplification for each speaker and a 20X voltage gain (26 dB). The board features adjustable volume control, RC filtering networks, and power supply filtering. I designed the schematic using Cadence OrCAD and completed the PCB layout in Cadence Allegro.

## Features

- Dual LM386 ICs for independent stereo audio amplification
- 20X voltage gain (26 dB) per channel
- Adjustable analog volume control
- 3.5 mm stereo audio input
- RC output stabilization networks
- Power supply filtering and decoupling capacitors

## Design

The schematic was created in Cadence OrCAD Capture and the PCB layout was completed in Cadence Allegro PCB Editor.

The repository includes the original project files along with the Gerber fabrication files.
